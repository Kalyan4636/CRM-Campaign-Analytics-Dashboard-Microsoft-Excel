## 📌 Project Overview

The **CRM Campaign Analytics Dashboard** is an interactive Microsoft Excel project designed to analyze customer relationship management (CRM) activities, communication channels, and campaign performance.

The dashboard presents important business metrics through KPI cards, charts, status breakdowns, and interactive dropdown filters. It helps users understand campaign activity, monitor communication performance, track completion rates, and identify trends in CRM operations.

This project demonstrates how Excel can be used to transform raw CRM records into a structured, visually appealing, and business-focused reporting solution.

### 🎯 Business Problem

CRM teams generate data across multiple communication channels, including calls, SMS, and email. Analyzing these activities manually can make it difficult to monitor performance, track campaign progress, and identify changes over time.

**The solution:** Build a centralized Excel dashboard that summarizes CRM activities, visualizes campaign performance, and enables users to explore results through interactive filters.

## ✨ Key Features

### 1. 📊 KPI Cards

Provides a quick overview of important CRM activity metrics, including:

- Call activity
- SMS activity
- Email activity
- Campaign completion rate
- Other available CRM activity totals

*The exact KPI values and definitions depend on the underlying dataset and workbook formulas.*

### 2. 📈 Monthly Campaign Performance

Visualizes campaign activity across reporting periods to help users:

- Identify monthly trends.
- Compare campaign performance.
- Recognize changes in activity volume.
- Monitor performance over time.

### 3. 🍩 Communication Channel Analysis

Analyzes the distribution of CRM activities across communication channels, such as:

- Phone calls
- SMS messages
- Email communications

This view helps users understand the contribution of each channel to overall CRM activity.

### 4. 🎯 Completion Rate and Status Breakdown

Tracks activity progress and displays the distribution of available CRM statuses.

Possible business applications include monitoring completed activities, identifying pending tasks, and understanding the overall progress of CRM campaigns.

### 5. 📋 Recent CRM Activity

Provides a summarized view of recent CRM records to help users review individual activities and monitor operational updates.

### 6. 🔽 Interactive Dropdown Filters

The dashboard includes dropdown filters for:

- **Period:** Explore CRM activity for a selected reporting period.
- **Channel:** Focus on a particular communication channel.

Filter behavior depends on how the controls, formulas, and charts are configured in the workbook.

### 7. 🎨 Modern Dashboard Design

The dashboard follows a modern, SaaS-inspired visual approach with a focus on:

- Clear KPI presentation
- Consistent visual hierarchy
- Easy-to-read charts
- Organized reporting sections
- Business-oriented data visualization

## 🧪 Data Validation and Quality Checks

Before using the dashboard for business reporting, consider validating:

- Duplicate activity identifiers.
- Missing activity dates or channel values.
- Inconsistent channel and status labels.
- Date values outside the intended reporting period.
- KPI calculations against the underlying records.
- Completion-rate denominators and numerator definitions.
- Filter behavior across charts and summary cards.
- Whether the dashboard totals reconcile with the source data.

These checks help improve reporting consistency and reduce the risk of misleading conclusions.
